HIVE MIND 2.0.4 FULL WINDOWS INSTALLER

1. Extract this ZIP.
2. Double-click INSTALL_HIVE_MIND.bat.
3. Existing Hive Memory installed data is automatically migrated if HIVE MIND has no database yet.
4. Application files install under %LOCALAPPDATA%\HiveMind\app and persistent data under %LOCALAPPDATA%\HiveMind\data.
5. Meta Llama 3.2 3B is provisioned for local/offline chat through a loopback-only Ollama service.

HIVE MIND includes per-user/per-vault encrypted chat, vault-specific ingestion settings, 20 GB streamed uploads, large-file streaming encryption, PST/MSG handling, OCR hooks, legacy Office extraction, RBAC, audit logging, backups, and the yellow/gunmetal branding.
